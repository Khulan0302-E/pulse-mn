# И-мэйлээр баталгаажуулах код (OTP) тохируулах

Бүртгүүлэх үед хэрэглэгчийн и-мэйл рүү 6 оронтой код очиж, түүнийг оруулж байж бүртгэл идэвхжинэ.
Код нь `noreply@pulse.mn` гэх мэт Pulse.mn-ийн хаягаас ирнэ.

Кодын тал бэлэн: Supabase дээр «Confirm email» асаалттай үед бүртгүүлэх хуудас автоматаар
«Баталгаажуулах код» оруулах алхам руу шилжинэ (`src/pages/Register.jsx`, `verifySignupOtp` — `src/api/auth.js`).
Асаагаагүй үед өмнөх шигээ код асуухгүй шууд нэвтэрнэ.

## 1. pulse.mn домэйн

`@pulse.mn` хаягаас илгээхийн тулд **pulse.mn домэйн өөрсдийнх байх** шаардлагатай
(одоо сайт `pulse-mn.vercel.app` дээр байгаа). .mn домэйныг бүртгэгчээс авна.
Домэйнгүй бол туршилтын үед доорх 2-р алхмын үйлчилгээний өгсөн хаягаас илгээж болно.

## 2. И-мэйл илгээх үйлчилгээ (SMTP)

Supabase-ийн өөрийн илгээгч зөвхөн **Supabase төслийн багийн гишүүдийн** хаяг руу,
**цагт 2** захиа илгээдэг тул жинхэнэ хэрэглэгчдэд ашиглах боломжгүй.
Supabase-ийн жагсаасан үйлчилгээнүүдээс нэгийг сонгоно: **Resend**, **Brevo**, Postmark, AWS SES, SendGrid, ZeptoMail.

1. Үйлчилгээнд бүртгүүлж, **pulse.mn домэйнээ нэмнэ**.
2. Үйлчилгээний өгсөн **SPF, DKIM, DMARC** бичлэгүүдийг домэйны DNS тохиргоонд нэмж, «Verified» болтол хүлээнэ.
   (Эдгээргүй бол захиа Spam руу орно.)
3. SMTP мэдээллийг хуулж авна: host, port (ихэвчлэн 587), username, password (API key).

## 3. Supabase-д SMTP холбох

Supabase → **Authentication** → **Emails** (SMTP Settings) → **Enable custom SMTP**:

| Талбар | Утга |
|---|---|
| Sender email | `noreply@pulse.mn` |
| Sender name | `Pulse.mn` |
| Host / Port / Username / Password | 2-р алхмын үйлчилгээнээс |

Custom SMTP асаасны дараа анхдагч хязгаар **цагт 30 захиа**; **Authentication → Rate Limits** хэсгээс нэмж болно.

## 4. Код илгээх загвар

Supabase → **Authentication** → **Emails** → **Templates** → **Confirm sign up**. Холбоосын оронд кодыг харуулна:

```html
<h2>Pulse.mn — бүртгэл баталгаажуулах</h2>
<p>Сайн байна уу! Таны баталгаажуулах код:</p>
<p style="font-size:28px;font-weight:700;letter-spacing:6px">{{ .Token }}</p>
<p>Энэ кодыг Pulse.mn-ийн бүртгүүлэх хуудсанд оруулна уу. Та бүртгүүлээгүй бол энэ захиаг үл тоомсорлоно уу.</p>
```

Subject: `Pulse.mn баталгаажуулах код`

## 5. «Confirm email»-ийг асаах

Supabase → **Authentication** → **Sign In / Providers** → **Email** → **Confirm email**-ийг **асаана**.
(Өмнө нь README-д унтраа гэж бичсэн байсан — кодын алхам нэмэгдсэн тул одоо асаана.)

**Authentication → URL Configuration → Site URL**-ийг жинхэнэ сайтын хаяг болгоно.

## 6. Шалгах

1. Шинэ и-мэйлээр бүртгүүлнэ → «И-мэйлээ баталгаажуулах» алхам гарна.
2. Ирсэн 6 оронтой кодыг оруулна → нэвтэрч орно (сэтгүүлч бол баримт нь Админд очно).
3. «Код дахин илгээх» нь 60 секундын дараа идэвхжинэ.
